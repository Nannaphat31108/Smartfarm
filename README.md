# Smart Farm 🌱

เว็บแอปควบคุมฟาร์มอัจฉริยะผ่านมือถือ (ESP32) — ควบคุมไฟ ปั๊มน้ำ และดูค่าเซนเซอร์ได้ทุกที่ ทุกเวลา

เป็นเว็บแบบ static (HTML/CSS/JS ล้วน ไม่ต้อง build) เปิด `index.html` ได้ทันที หรือเปิดใช้ GitHub Pages ได้เลย

## หน้าจอ
- **หน้าแรก** — เริ่มต้นใช้งาน
- **หน้าหลัก** — อุณหภูมิ ความชื้นอากาศ ความชื้นดิน, ควบคุมด่วน (ไฟ/ปั๊ม/อัตโนมัติ/แจ้งเตือน), ค่าเซนเซอร์
- **อุปกรณ์** — ค้นหา + กรอง (ควบคุม/เซนเซอร์), สวิตช์เปิด-ปิดรีเลย์
- **ไฟปลูกต้นไม้** — โหมดตามเวลา / ตามแสง / สั่งเอง, ตั้งเวลา
- **ปั๊มน้ำ** — เกจความชื้นดิน, ปรับเกณฑ์รดน้ำอัตโนมัติ, รดน้ำทันที
- **อัตโนมัติ** — เพิ่ม/แก้ไข/ลบ/เปิด-ปิดกฎ (ตั้งเวลา, ความชื้นดิน, แสงน้อย, อุณหภูมิสูง)
- **ข้อมูล** — กราฟย้อนหลัง 24 ชม. / 7 วัน และสรุปค่าเซนเซอร์

การตั้งค่าและข้อมูลถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์

## เชื่อมต่อ ESP32
ค่าเริ่มต้นเป็น **โหมดจำลอง** (สุ่มค่าเซนเซอร์ให้) — เปลี่ยนเป็นข้อมูลจริงได้ที่หน้า ไฟปลูก/ปั๊มน้ำ → เมนู ⋮ → *ตั้งค่าการเชื่อมต่อ ESP32* แล้วใส่ URL เช่น `http://192.168.1.50`

ESP32 ต้องมี endpoint (และเปิด CORS):

| Method | Path | ข้อมูล |
|---|---|---|
| GET | `/sensors` | `{"temp":31.2,"hum":68,"soil":46,"lux":12400,"tank":72,"soilTemp":27.5,"light":true,"pump":false}` |
| POST | `/relay` | `{"channel":1,"on":true}` (ช่อง 1 = ไฟ, ช่อง 2 = ปั๊ม, มี `minutes` เมื่อสั่งรดน้ำ) |

> หมายเหตุ: หากเว็บเปิดผ่าน HTTPS (เช่น GitHub Pages) เบราว์เซอร์จะบล็อกการเรียก `http://` ใน LAN — ให้เปิดไฟล์ในเครื่องหรือโฮสต์บน ESP32 เอง

อุปกรณ์อ้างอิง: รีเลย์ 2 ช่อง, Capacitive soil sensor (GPIO34), DHT22 (GPIO4), BH1750 (I2C), JSN-SR04T
