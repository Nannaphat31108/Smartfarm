# คู่มือต่อวงจร Smart Farm (ฉบับเต็ม)

อุปกรณ์ชุดสุดท้าย: ESP32 DevKit V1 · SHT40 (อากาศ ตัวหลัก) · DHT22 (อากาศ ตัวสำรอง) · เซนเซอร์ความชื้นดิน Capacitive v1.2 · BH1750 (แสง) · รีเลย์ 2 ช่อง · ไฟปลูก 12V · ปั๊มน้ำ 12V · ESP32-CAM (AI-Thinker)

> ในแอป/เว็บมีหน้า **ต่อวงจรและวิธีทำ** ที่มีผังสายเป็นภาพและเช็กลิสต์ — ไฟล์นี้คือฉบับละเอียดสำหรับอ่านประกอบ

---

## 1. ภาพรวมระบบไฟ

```
                    ┌──────────────── ราง 12V+ ────────────────┐
อะแดปเตอร์ 12V 3A ──┤                                          ├──► รีเลย์ COM1 ──NO1──► ไฟปลูก (+)
   (แจ็ค DC)        │                                          └──► รีเลย์ COM2 ──NO2──► ปั๊มน้ำ (+)
                    └──► LM2596 IN+        LM2596 OUT+ (5.0V) ──► ราง 5V ──► ESP32 VIN
                                                                        ├──► รีเลย์ VCC
                                                                        └──► ESP32-CAM 5V
                         ESP32 3V3 ──► ราง 3V3 ──► SHT40, BH1750, DHT22, เซนเซอร์ดิน

ราง GND (ร่วมทั้งหมด): อะแดปเตอร์ − , LM2596 IN− / OUT− , ESP32 GND , รีเลย์ GND ,
                      เซนเซอร์ทุกตัว , ESP32-CAM GND , ไฟปลูก (−) , ปั๊มน้ำ (−)
```

**หลักสำคัญ**
- มี 4 ราง: **12V**, **5V**, **3V3**, **GND** — ใช้เทอร์มินอลบล็อกหรือแผ่น PCB อเนกประสงค์ทำเป็นรางไว้ แล้วแยกสายไปแต่ละอุปกรณ์
- **GND ทุกตัวต้องต่อถึงกัน** ไม่งั้นเซนเซอร์และรีเลย์จะทำงานเพี้ยน
- เซนเซอร์ทุกตัวใช้ **3V3** (ห้ามต่อ 5V) · รีเลย์และ ESP32-CAM ใช้ **5V** · ไฟปลูกและปั๊มใช้ **12V** ผ่านหน้าสัมผัสรีเลย์

## 4. ขั้นตอนต่อวงจร (ทำตามลำดับ)

> ⚠️ **ถอดปลั๊กอะแดปเตอร์และสาย USB ทุกครั้งก่อนต่อหรือแก้สาย**

### ขั้นที่ 1 — ปรับ LM2596 ให้ได้ 5.0V (ก่อนต่ออะไรทั้งนั้น)
1. ต่ออะแดปเตอร์ 12V เข้า **IN+ / IN−** ของ LM2596 เท่านั้น (ยังไม่ต่อ OUT ไปไหน)
2. เสียบปลั๊ก → เอามัลติมิเตอร์ (โหมด DC V) วัดที่ **OUT+ / OUT−**
3. หมุนสกรูทองเหลืองบนตัวปรับ (trimpot) จนอ่านได้ **5.0–5.1V** (มักต้องหมุนทวนเข็มหลายรอบ)
4. ถอดปลั๊ก

### ขั้นที่ 2 — ทำราง 12V / 5V / 3V3 / GND
- ใช้เทอร์มินอลบล็อก 4 แถว หรือ PCB อเนกประสงค์ แยกเป็น 4 ราง
- ต่อสาย **P1–P8** ตามตาราง 3.1
- เสียบปลั๊ก → วัดราง 5V ต้องได้ ~5V, ไฟ LED บน ESP32 ต้องติด → ถอดปลั๊ก
- ต่อ **P9** (ESP32 3V3 → ราง 3V3)

### ขั้นที่ 3 — อัปโหลดโค้ดและทดสอบบอร์ดเปล่า
1. ติดตั้ง Arduino IDE + ESP32 core + ไลบรารี: **Adafruit SHT4x Library, DHT sensor library, Adafruit Unified Sensor, BH1750, ArduinoJson**
2. เปิด `firmware/smartfarm/smartfarm.ino` แก้ `WIFI_SSID` / `WIFI_PASS` (Wi-Fi 2.4GHz)
3. **ถอดอะแดปเตอร์ออกก่อน** แล้วเสียบ USB → เลือกบอร์ด **ESP32 Dev Module** → Upload
4. Serial Monitor (115200) ต้องเห็น `Smart Farm ready: http://192.168.x.x` → จด IP

> ขณะเสียบ USB กับคอม **อย่าเสียบอะแดปเตอร์พร้อมกัน** (ไฟ 5V สองแหล่งชนกัน)

### ขั้นที่ 4 — ต่อ SHT40 และ BH1750 (บัส I2C)
- ต่อสาย **S1–S9** — SHT40 กับ BH1750 ใช้ SDA/SCL **เส้นเดียวกัน** (ต่อขนานกันที่ GPIO 21 / 22)
- สาย I2C ยาวได้ไม่เกิน ~1 เมตร ถ้าต้องวางเซนเซอร์ไกล ให้ใช้สายตีเกลียว/สายชีลด์
- รีเซ็ตบอร์ด → Serial Monitor ต้องเห็น `[SHT40 xx.x/xx ...]` และค่า `lux`
  - ขึ้น "ไม่พบ SHT40" หรือ "ไม่พบ BH1750" → ตรวจว่าไม่ได้สลับ SDA/SCL และต่อ 3V3/GND แน่น

### ขั้นที่ 5 — ต่อ DHT22 (ตัวสำรอง ข้ามได้)
- ต่อสาย **S10–S12**
- ถ้าเป็นตัวเปล่า 4 ขา: ขา 1 = VCC, ขา 2 = DATA, ขา 3 = ไม่ต่อ, ขา 4 = GND และใส่ **10kΩ ระหว่างขา 1 กับขา 2**
- Serial Monitor ต้องเห็นค่า `DHT22 xx.x/xx`

### ขั้นที่ 6 — ต่อเซนเซอร์ความชื้นดิน + คาลิเบรต
1. ต่อสาย **S13–S15**
2. ถือเซนเซอร์ไว้ในอากาศ → ดูค่า `raw` ใน Serial Monitor → ใส่ใน `SOIL_DRY`
3. จุ่มน้ำแค่ถึงขีดเส้น (ห้ามให้น้ำโดนวงจรด้านบน) → ดูค่า `raw` → ใส่ใน `SOIL_WET`
4. อัปโหลดโค้ดใหม่ → ปักลงดิน ค่า % ควรอยู่ระหว่าง 30–70 ในดินที่ชื้นพอดี
5. หุ้มส่วนวงจรด้านบนด้วยท่อหดหรือทาซิลิโคนกันน้ำ

### ขั้นที่ 7 — ต่อรีเลย์ฝั่งควบคุม และทดสอบ (ยังไม่ต่อไฟปลูก/ปั๊ม)
1. ต่อสาย **R1–R4**
2. เสียบอะแดปเตอร์ → เปิดแอป → ตั้งค่าการเชื่อมต่อ ESP32 ใส่ `http://IP-ของบอร์ด`
3. กดเปิด/ปิด **ไฟปลูก** และ **ปั๊ม** ในแอป → ต้องได้ยินเสียง "คลิก" และ LED บนรีเลย์ติด/ดับตาม
   - ถ้ากดเปิดแล้วรีเลย์ **ดับ** (กลับด้าน) → แก้ `RELAY_ACTIVE_LOW = false` แล้วอัปโหลดใหม่
4. ถอดปลั๊ก

### ขั้นที่ 8 — ต่อไฟปลูกและปั๊ม 12V
1. ต่อสาย **L1–L6** ด้วยสายเส้นใหญ่ ขันน็อตเทอร์มินอลให้แน่น
2. บัดกรี/ขันไดโอด **L7** คร่อมขั้วปั๊ม — **ขีดสีเงินไปขั้วบวก**
3. ตรวจด้วยมัลติมิเตอร์ (โหมดวัดความต่อเนื่อง/ปี๊บ) ก่อนเสียบปลั๊ก — ดูหัวข้อ 5
4. เสียบปลั๊ก → ทดสอบเปิด/ปิดจากแอปอีกครั้ง ไฟปลูกต้องติด ปั๊มต้องหมุน

### ขั้นที่ 9 — ESP32-CAM
1. เสียบ ESP32-CAM บนฐาน ESP32-CAM-MB → ต่อ USB
2. เปิด `firmware/esp32cam/esp32cam.ino` แก้ Wi-Fi → บอร์ด **AI Thinker ESP32-CAM**, Partition **Huge APP** → Upload (ถ้าค้างที่ Connecting… กดปุ่ม IO0 บนฐานค้างไว้)
3. Serial Monitor → กด RST → จด IP จาก `Camera ready: http://...`
4. ถอดออกจากฐาน → ต่อ **C1–C2** เข้าราง 5V/GND (หรืออะแดปเตอร์ 5V 2A แยก)
5. ในแอป แท็บ **กล้อง** → การเชื่อมต่อ → ใส่ IP

### ขั้นที่ 10 — ใส่กล่องและติดตั้ง
- ใส่ ESP32, LM2596, รีเลย์ และรางไฟ ไว้ในกล่องกันน้ำ ร้อยสายออกทางเคเบิลแกลนด์
- วางกล่องให้สูงจากพื้น ไม่โดนน้ำจากการรดน้ำ
- **SHT40 / DHT22** ไว้นอกกล่อง ในที่ร่ม อากาศถ่ายเท (ในกล่องจะร้อนกว่าข้างนอก ค่าเพี้ยน)
- **BH1750** หงายหน้ารับแสง ใส่ฝาครอบใสถ้าโดนฝน
- **ESP32-CAM** หันเข้าแปลง ไม่ย้อนแสง ใส่กล่องที่มีหน้าต่างใส

## 5. เช็กลิสต์ก่อนเสียบปลั๊กครั้งแรก

ใช้มัลติมิเตอร์โหมดวัดความต่อเนื่อง (ปี๊บ) ตอน **ไม่ได้เสียบปลั๊ก**:

- [ ] ราง 12V กับ GND — **ต้องไม่ปี๊บ** (ถ้าปี๊บ = ช็อต ห้ามเสียบปลั๊ก)
- [ ] ราง 5V กับ GND — ต้องไม่ปี๊บ
- [ ] ราง 3V3 กับ GND — ต้องไม่ปี๊บ
- [ ] ราง 12V **ไม่ได้** ต่อเข้าราง 5V หรือ 3V3 หรือขา ESP32 ใด ๆ
- [ ] LM2596 วัดแล้วได้ 5.0V จริง
- [ ] เซนเซอร์ทุกตัวต่อ 3V3 ไม่ใช่ 5V
- [ ] ไดโอดปั๊มหันขีดสีเงินไปขั้วบวก
- [ ] ไฟปลูก/ปั๊มต่อที่ขา **NO** ไม่ใช่ NC

## 6. ผลที่ควรเห็นใน Serial Monitor

```
=== Smart Farm ESP32 ===
Connecting WiFi.....
Smart Farm ready: http://192.168.1.50  (http://smartfarm.local)
T=29.4 H=70 [SHT40 29.4/70 DHT22 29.8/68] soil=46% (raw 2210) lux=12450 light=0 pump=0
```

- `nan` ที่ SHT40 = ไม่พบ SHT40 (ระบบใช้ DHT22 แทน)
- `nan` ทั้งคู่ = ไม่มีเซนเซอร์อากาศเลย ตรวจสาย
- `lux=nan` = ไม่พบ BH1750
- `raw` ไม่เปลี่ยนเลยตอนจุ่มน้ำ/ยกขึ้น = สาย AOUT หลุด หรือต่อผิดขา

## 7. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ | วิธีแก้ |
|---|---|---|
| ESP32 รีสตาร์ทเอง ตอนรีเลย์/ปั๊มทำงาน | ไฟ 5V ตก, GND ไม่ร่วม | เช็ก LM2596 5.0V, ต่อ GND ร่วม, ใส่ไดโอดคร่อมปั๊ม, ใส่ตัวเก็บประจุ 470–1000µF คร่อมราง 5V |
| รีเลย์ทำงานกลับด้าน | โมดูลเป็นแบบ active HIGH | `RELAY_ACTIVE_LOW = false` |
| รีเลย์คลิกแต่ไฟปลูก/ปั๊มไม่ทำงาน | ต่อที่ NC, ไม่ได้จั๊มป์ COM1–COM2, สายหลวม | ย้ายไป NO, ต่อ L2, ขันเทอร์มินอลแน่น |
| ไม่พบ SHT40 / BH1750 | สลับ SDA/SCL, ลืม 3V3/GND, สายยาวเกิน | ตรวจขา 21=SDA, 22=SCL, ใช้สายสั้นลง |
| ความชื้นดินค้าง 0% หรือ 100% | ยังไม่คาลิเบรต | ตั้ง `SOIL_DRY` / `SOIL_WET` ใหม่ |
| แอปเชื่อมต่อไม่ได้ | IP เปลี่ยน, มือถือคนละ Wi-Fi, เปิดผ่านเว็บ https | ดู IP ใหม่ใน Serial Monitor, ใช้ Wi-Fi เดียวกัน, ใช้แอป Android |
| ESP32-CAM รีสตาร์ทวน (brownout) | ไฟไม่พอ | ใช้อะแดปเตอร์ 5V 2A แยก, สายไฟสั้นและใหญ่ขึ้น |
| อัปโหลด ESP32-CAM ไม่ได้ | ไม่ได้เข้าโหมดแฟลช | กด IO0 ค้างบนฐาน MB ระหว่างอัปโหลด |

## 8. ความปลอดภัย
- ระบบนี้ใช้ไฟ 12V ทั้งหมด **ไม่ต้องต่อไฟบ้าน 220V** — ถ้าจะใช้หลอด/ปั๊ม 220V ให้ช่างไฟฟ้าต่อ และใส่กล่องปิดมิดชิด
- ถอดปลั๊กทุกครั้งก่อนแก้สาย · ตรวจช็อตด้วยมิเตอร์ก่อนเสียบปลั๊กครั้งแรก
- จุดต่อสายฝั่ง 12V หุ้มท่อหดให้มิด ไม่ให้โดนน้ำ
